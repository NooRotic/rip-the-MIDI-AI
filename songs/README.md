# songs/

MIDI (and later MusicXML) that the trainer and the lighted-key player read.

- `songs/public/` is **tracked.** Public-domain pieces and exercises we wrote ourselves. Sources:
  [Mutopia](https://www.mutopiaproject.org/), [musetrainer/library](https://github.com/musetrainer/library),
  [IMSLP](https://imslp.org/) (check the licence per file).
- Everything else in `songs/` is **gitignored.** Personal transcriptions of copyrighted music (the snippets
  being learned) stay on this machine. Hand-transcribing a few bars for your own practice is fine; publishing
  the file is not.

Name files `artist--title--part.mid`, for example `my-band--my-song--intro-rh.mid`.
